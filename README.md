## 🚀 Overview

In an era where **Generative AI** and **Deepfake** technologies are rapidly advancing, distinguishing real faces from synthetic ones has become a critical challenge across security, journalism, law enforcement, and social media platforms.

**VeriFace** addresses this challenge head-on by leveraging state-of-the-art deep learning models trained on diverse datasets to detect and classify facial images into three distinct categories with high confidence and real-time performance.

### Why VeriFace?

| Problem | VeriFace Solution |
|---|---|
| 📰 Misinformation with fake faces | Flags AI-generated & deepfake content |
| 🔐 Identity fraud using synthetic faces | Verifies biometric authenticity |
| 🎭 Impersonation via deepfake videos | Detects manipulation artifacts |
| 🤖 AI portrait abuse on platforms | Classifies GAN/diffusion-generated images |

---

## 🎯 Detection Categories

VeriFace classifies every input into **one of three categories**:

<br/>

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│   ✅  REAL          Authentic, unmanipulated human photographs      │
│                                                                     │
│   ⚠️  DEEPFAKE      Face-swapped or reenacted media using AI        │
│                                                                     │
│   🤖  AI-GENERATED  Fully synthetic faces from GAN / Diffusion AI  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Detection Breakdown

| Category | Description | Examples |
|---|---|---|
| ✅ **Real** | Genuine photographs of real humans | Camera photos, ID images, selfies |
| ⚠️ **Deepfake** | AI-manipulated video/image with face swap | FaceSwap, DeepFaceLab, FaceApp |
| 🤖 **AI-Generated** | Fully synthetic faces generated by AI models | StyleGAN, DALL-E, Midjourney, Stable Diffusion |

## 🔬 How It Works

VeriFace uses a multi-stage detection pipeline combining spatial, frequency, and semantic analysis:

```
Input Image / Video Frame
          │
          ▼
 ┌────────────────────┐
 │   Preprocessing    │  ← Face alignment, normalization, resizing
 └────────────────────┘
          │
          ▼
 ┌────────────────────┐
 │   Face Detection   │  ← Locate and crop facial region
 └────────────────────┘
          │
     ┌────┴────┐
     ▼         ▼
┌─────────┐ ┌────────────────┐
│ Spatial │ │  Frequency     │  ← DCT / FFT artifact analysis
│Analysis │ │  Analysis      │
└─────────┘ └────────────────┘
     │         │
     └────┬────┘
          ▼
 ┌────────────────────┐
 │  Feature Fusion    │  ← Combine spatial + frequency features
 └────────────────────┘
          │
          ▼
 ┌────────────────────┐
 │  Classification    │  ← Multi-class softmax output
 │  Head              │
 └────────────────────┘
          │
          ▼
 ┌────────────────────────────────────┐
 │ Result: Real / Deepfake / AI-Gen   │
 │ Confidence: [0.94, 0.04, 0.02]    │
 └────────────────────────────────────┘
```

### Detection Signals

| Signal Type | What It Catches |
|---|---|
| **Spatial Artifacts** | Blending boundaries, unnatural textures, face warping |
| **Frequency Analysis** | GAN fingerprints, DCT anomalies, noise inconsistencies |
| **Semantic Cues** | Inconsistent lighting, eye reflections, background mismatch |
| **Compression Patterns** | JPEG artifacts mismatched with claimed authenticity |

## 🏗️ Architecture

```
VeriFace Detection Model
────────────────────────────────────────────────────────
Input (224×224 RGB)
        │
        ▼
 EfficientNet-B4 / Xception  ←──  Pretrained Backbone
 (Feature Extractor)
        │
        ├──────────────────────────────────────────┐
        ▼                                          ▼
 Spatial Feature Branch               Frequency Branch
 [Conv → BN → ReLU]                   [FFT → Conv → Pool]
        │                                          │
        └──────────────┬───────────────────────────┘
                       ▼
               Feature Fusion Layer
               [Concat → FC → Dropout]
                       │
                       ▼
               Classification Head
               [FC(512) → FC(3) → Softmax]
                       │
                       ▼
         ┌─────────────────────────────┐
         │  Real  |  Deepfake  |  AI   │
         └─────────────────────────────┘
```

## ⚙️ Installation

### Prerequisites

- Python 3.10+
- pip or conda
- CUDA-compatible GPU (recommended)

---

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/VeriFace.git
cd VeriFace
```

### 2. Create Virtual Environment

```bash
python -m venv venv
```

### 3. Activate Environment

**Windows:**
```bash
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Download Pretrained Models

```bash
python scripts/download_models.py
```

## ▶️ Usage

### Analyze a Single Image

```bash
python main.py --image path/to/image.jpg
```

**Output:**
```
────────────────────────────────
 VeriFace — Authenticity Report
────────────────────────────────
 Image     : portrait.jpg
 Prediction: REAL ✅
 Confidence:
   ├── Real         : 96.3%
   ├── Deepfake     :  2.1%
   └── AI-Generated :  1.6%
────────────────────────────────
```

---

### Batch Process a Folder

```bash
python batch_analyze.py --input ./images/ --output ./results/report.json
```

---

### Real-Time Webcam Analysis

```bash
python webcam.py
```

---

### Run the REST API

```bash
uvicorn api.main:app --host 0.0.0.0 --port 8000
```

**API Endpoint:**

```http
POST /api/v1/analyze
Content-Type: multipart/form-data

{
  "file": <image_file>
}
```

**Response:**
```json
{
  "prediction": "deepfake",
  "confidence": {
    "real": 0.04,
    "deepfake": 0.91,
    "ai_generated": 0.05
  },
  "verdict": "⚠️ DEEPFAKE DETECTED",
  "processing_time_ms": 47
}
```

---

### Run with Docker

```bash
docker build -t veriface .
docker run -p 8000:8000 veriface
```

## 🔒 Ethics & Responsible Use

VeriFace is built with ethical considerations at its core.

> **⚠️ Intended Use Only**
> This tool is designed to **detect and expose** synthetic and manipulated media, not to create it. Misuse of this technology to target individuals, bypass security systems, or infringe on privacy is strictly prohibited.

### Principles

- 🔍 **Transparency** — Confidence scores surface uncertainty; no black-box verdicts.
- ⚖️ **Fairness** — Models are evaluated across diverse demographics to minimize bias.
- 🔐 **Privacy** — No user images are stored, logged, or used for retraining without consent.
- 📢 **Accountability** — Designed for responsible deployment in compliance with applicable laws.

### Acceptable Use Cases

✅ Media verification and journalism  
✅ Platform trust & safety moderation  
✅ Identity verification security research  
✅ Academic and forensic research  
✅ Fraud prevention and KYC pipelines  

### Not Intended For

❌ Surveillance without consent  
❌ Political targeting or manipulation  
❌ Profiling or discriminatory use
